Simple Brainwind Example

The San Marzano Tomatoes are harvested from the volcanic soil of Mount Vesuvius .

What this creates:

  • Subject: San Marzano Tomatoes (Product)
  • Predicate: grownIn
  • Object: Mount Vesuvius (Place)

Open browser console to see extracted semantic data.

// Extract and display semantic data const nodes = document.querySelectorAll('.bw-node'); const edges = document.querySelectorAll('.bw-edge'); console.log('🧠 Brainwind Semantic Data:'); console.log(`Entities: ${nodes.length}`); console.log(`Relationships: ${edges.length}`); nodes.forEach(node => { console.log({ id: node.getAttribute('data-bw-id'), type: node.getAttribute('data-bw-type'), text: node.textContent.trim() }); });
